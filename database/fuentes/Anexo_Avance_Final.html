A.3 Corrección al protocolo de la sección 5.1

La base del proyecto se llama peajesys_db (como en el README y en la configuración de la API), no peajesys, y \i es un comando de la consola psql que no funciona en el Query Tool de pgAdmin. El procedimiento correcto es:

-- Consola (psql), desde la carpeta database/
psql -U postgres -d postgres -c "DROP DATABASE IF EXISTS peajesys_db;"
psql -U postgres -d postgres -c "CREATE DATABASE peajesys_db;"
psql -U postgres -d peajesys_db -f 00_Master_PeajeSys.sql

-- pgAdmin 4: crear la base peajesys_db, abrir el Query Tool sobre ella,
-- abrir 00_Master_PeajeSys.sql y ejecutar con F5.

-- Docker (desde la raíz del repositorio): reconstruye la base desde cero
docker compose down -v && docker compose up -d

La demostración del error intencional de la sección 5.1 no cambia: tras cargar el maestro devuelve «Saldo insuficiente … (SQLSTATE: P0016)», verificado el 23-nov-2026.
